# Desktop reference configuration

`gnome-extension-profile.json` contains GVariant values for the accepted
Dash to Dock and TouchUp profile. The upstream extensions are downloaded
separately; their binaries/resources are not bundled here. See
[GNOME extensions](../../docs/GNOME_EXTENSIONS.md) for versions, source URLs,
installation and the measured scope.

`protected-package-versions.json` records the reference device's inspected
custom and desktop support packages. It is not a list to apply blindly to every
Void system. See [Void updates](../../docs/UPDATING.md) for ownership checks and
the native hold validation.
